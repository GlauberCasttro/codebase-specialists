# E1 — Análise da demanda

Demanda (literal): "Siga com seus proximos passos." — sobre o passo proposto: "recopiar o motor corrigido para
`.claude/tools/ac/` e atualizar o `ORIGEM.txt`" (B-16), dentro de "atacar todas as frentes aqui no Windows" e "use a
/auto-correcao".

Problema por trás: o motor de campanhas embutido neste harness (`.claude/tools/ac/`, ORIGEM `da3ea45`) é o de antes
das campanhas win-motor e win-hook do projeto `auto-correcao`. Nesta máquina Windows ele não deixa uma campanha
desta skill andar sem a WSL: a frase do founder só entra por `/dev/tty` + `termios` (o `gate stop` da abertura é
impossível no PowerShell), `load`/`status` quebram com saída cp1252, o hash do oráculo muda com CRLF (este clone tem
`core.autocrlf=true`), e o hook de aprovação do projeto não enxerga a ferramenta PowerShell — um agente aprovaria
por ela sem ser barrado (só a frase segura). Toda feature seguinte (B-15, B-14) depende desse motor.

O que NÃO é: não é corrigir o motor (já corrigido e medido no `auto-correcao`, commits `3e81f49` e `30e2da6`); não é
o resto do harness no Windows (`python3`/`bash` fixos nos tools, régua com 2 Pythons POSIX, `.gitattributes`,
`/install` com junction — isso é a B-15); não é o produto (B-14); não é publicar pacote. Não muda o comportamento
do motor no macOS/Linux além do que as duas campanhas de origem já provaram.

Perguntas abertas (máx. 3, só as que mudam o desenho):
1. De onde copiar, já que o `main` do `auto-correcao` ainda não tem as correções?
   → recomendo: do commit `30e2da6` da branch `release/version-windows` (último que toca `scripts/` e
     `references/`), registrado no `ORIGEM.txt` com o sha256 de cada arquivo — medido: `git log -1 -- scripts/
     references/` no `auto-correcao` = `30e2da6`.
     alternativa: esperar o merge no `main` do `auto-correcao` e copiar de lá (atrasa B-15/B-14).
2. As 2 linhas do layout embutido (procurar `references/` ao lado do `ac.py`) continuam aqui ou sobem para a fonte?
   → recomendo: reaplicar aqui, como hoje — medido: o `ac.py` de `30e2da6` ainda resolve `CICLO` só pela pasta-pai
     (linha 35); mudar a fonte é outra frente no `auto-correcao`.
     alternativa: abrir uma frente no `auto-correcao` para a fonte procurar nos dois lugares e copiar sem ajuste.
3. O registro do hook neste projeto (`.claude/settings.json`, hoje `"matcher": "Bash"` na linha 15) entra junto?
   → recomendo: sim, só o matcher para `Bash|PowerShell` — sem isso o hook novo não vê a ferramenta PowerShell e o
     ganho de segurança da win-hook não chega aqui. O `python3` do comando fica para a B-15.
     alternativa: deixar o matcher para a B-15 (fica uma janela em que o PowerShell não é vigiado aqui).
